# Week 1 Database Assignment

This project creates a School Management database using MySQL.

## Contents

- `answer.sql` - creates the database and tables, inserts sample records, and displays student enrollments.

## Database

The `school_management` database contains four related tables:

- `teachers`
- `students`
- `courses`
- `enrollments`

## How to Run

1. Open MySQL Workbench or the MySQL command-line client.
2. Open `answer.sql`.
3. Run the full script.

You can also run it from the MySQL command line:

```sql
source answer.sql
```
